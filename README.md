# Thendo Events & Catering

Responsive website for Thendo Events, a professional event planning and catering business.

## Features
- Modern black and colorful design
- Responsive layout for desktop and mobile
- Event service showcase
- Gallery with full-screen image browsing
- Contact information and enquiry form

## Project Structure
- `1. Project/Site/` - main website files
